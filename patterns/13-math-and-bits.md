## 1. Как узнать задачу

| Что написано в условии | Приём |
|---|---|
| Работа с цифрами числа, «без преобразования в строку» | цикл `% 10` и `/ 10` |
| Число хранится массивом цифр, сложить или прибавить | перенос с конца |
| Сдвинуть массив по кругу на k | три разворота |
| Простые числа до n | решето Эратосфена |
| НОД, НОК, сократить дробь | алгоритм Евклида |
| Возвести в степень, n до 10⁹ | быстрое возведение в степень |
| «Ответ по модулю 10⁹ + 7» | арифметика по модулю, тип `long` |
| Все числа встречаются дважды, одно — один раз; O(1) памяти | XOR |
| Посчитать единичные биты, проверить степень двойки | `x & (x - 1)` |
| Круговой массив, круговая очередь | индекс по модулю |

## 2. Цифры числа

```java
while (x > 0) {
    int digit = x % 10;     // последняя цифра
    x /= 10;                // отбросить её
}
```

Развернуть число: `reversed = reversed * 10 + digit`.

[isPalindrome](../src/leetcode/challenges/Palindrome.java) (LC 9): разворачиваем только половину числа — пока оставшаяся часть больше развёрнутой. Так нет риска переполнения. Отдельные случаи: отрицательные числа и числа, оканчивающиеся на 0 (кроме самого нуля), палиндромами не являются.

[plusOneShort](../src/leetcode/easy/EasySolutions.java) (LC 66): идём с конца. Цифра меньше 9 — увеличиваем и сразу возвращаем ответ. Девятка превращается в 0, перенос идёт дальше. Если цикл закончился, значит были одни девятки и нужен новый массив на один длиннее с единицей в начале.

## 3. Разворот как инструмент

[rotate](../src/leetcode/medium/MediumSolutions.java) (LC 189). Сдвиг вправо на k за O(1) памяти:

1. развернуть весь массив;
2. развернуть первые k элементов;
3. развернуть остальные.

Перед этим обязательно `k %= n`: сдвиг на n возвращает массив в исходное состояние, а k может быть больше n.

Сам разворот — два указателя навстречу с условием `left < right`.

## 4. Теория чисел

**НОД (алгоритм Евклида):**

```java
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

НОК: `a / gcd(a, b) * b`. Сначала делим, потом умножаем — так меньше риск переполнения.

**Решето Эратосфена** — [Primes](../src/fox/Primes.java) (≈LC 204):

```java
boolean[] composite = new boolean[n + 1];
for (int d = 2; (long) d * d <= n; d++) {
    if (composite[d]) continue;
    for (int m = d * d; m <= n; m += d) composite[m] = true;
}
```

- Вычёркивать начинаем с `d * d`: меньшие кратные уже вычеркнуты меньшими простыми.
- Внешний цикл идёт до корня из n: у составного числа есть делитель не больше корня.
- `d * d` считаем в `long`, иначе переполнится.

**Быстрое возведение в степень.** Вместо n умножений — log n: если степень чётная, возводим основание в квадрат и делим степень пополам; если нечётная — один раз домножаем результат.

```java
long power(long base, long exp, long mod) {
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}
```

Та же идея удвоения для чисел Фибоначчи — [FibonacciMod](../src/ya/algorithm_course/second_sprint_recursion/FibonacciMod.java): O(log n) вместо O(n).

**Арифметика по модулю:**

- Брать остаток после каждого сложения и умножения, а не один раз в конце.
- Перед умножением приводить к `long`.
- Вычитание: `(a - b + mod) % mod`. В Java остаток от отрицательного числа отрицательный.

## 5. Биты

| Выражение | Что делает |
|---|---|
| `x & 1` | последний бит: 1 для нечётного числа |
| `x >> 1` | деление на 2 |
| `1 << k` | число с единственной единицей в бите k, то есть 2ᵏ |
| `x & (1 << k)` | не ноль, если бит k установлен |
| `x \| (1 << k)` | установить бит k |
| `x & (x - 1)` | сбросить младший единичный бит |
| `x ^ x` | 0; `x ^ 0` равно `x` |

- **Единственное число без пары** (LC 136): XOR всех чисел. Парные дают ноль, остаётся одиночное.
- **Степень двойки:** `x > 0 && (x & (x - 1)) == 0` — в записи ровно один единичный бит.
- **Количество единичных битов** (LC 191): применять `x &= x - 1`, пока `x` не станет нулём, и считать шаги.
- **Подмножества через маски:** при n ≤ 20 число от 0 до `(1 << n) - 1` кодирует подмножество; бит k говорит, взят ли элемент k.

В Java `>>` сохраняет знак, `>>>` заполняет нулями. Для отрицательных чисел в цикле нужен `>>>`, иначе цикл не закончится.

## 6. Задача без приёма: H-Index

[hIndex](../src/leetcode/medium/MediumSolutions.java) (LC 274). Трудность в формулировке, поэтому её стоит переписать своими словами: наибольшее h такое, что хотя бы h статей имеют не меньше h цитирований. После сортировки по убыванию это наибольшее i, для которого i-я по счёту статья имеет не меньше i цитирований.

Общий урок: если определение в условии запутанное, сначала переформулировать его и проверить на примере, и только потом искать алгоритм.

## 7. Переполнение

Места, где оно случается чаще всего:

- сумма элементов массива при значениях до 10⁹ — нужен `long`;
- произведение двух `int`;
- `(left + right) / 2` в бинарном поиске;
- `d * d` в условии цикла;
- компаратор через вычитание;
- `Math.abs(Integer.MIN_VALUE)` остаётся отрицательным;
- разворот числа (LC 7).

Подсказка из ограничений: значения до 10⁹ и их складывают или умножают — сразу брать `long`.

## 8. С чем не путать

| Выглядит как | Но на самом деле | Как отличить |
|---|---|---|
| Проверка каждого числа на простоту | решето | нужны все простые до n, а не одно число |
| Цикл из n умножений | быстрое возведение в степень | n до 10⁹ |
| `HashSet` для поиска одиночного числа | XOR | просят O(1) памяти |
| Сдвиг массива через дополнительный массив | три разворота | просят O(1) памяти |
| Симуляция по шагам | формула или остаток от деления | количество шагов огромное, процесс цикличен |
